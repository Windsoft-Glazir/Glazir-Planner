# Glazir Planner

**BIM 모델과 공정표를 연결해 브라우저에서 시공 순서를 확인하는 4D BIM 공정 시뮬레이션 도구입니다.** 현재 개발 중이며, 아래는 공식 홈페이지에 소개된 제품 범위입니다.

## 제품 범위

- **공정과 모델 객체 자동 매칭** — 공정 이름을 분석해 층과 카테고리에 맞는 모델 객체를 연결합니다. 매칭 결과는 작업 단위별 객체 그룹(Sets)에서 조정합니다.
- **웹 BIM 뷰어** — Autodesk APS 기반으로 Revit, Navisworks, IFC 등의 모델을 열고 단면·객체 속성·관측점을 확인합니다. Autodesk ACC 및 BIM 360 Docs 연동도 포함합니다.
- **Excel 공정표와 Gantt** — Excel 공정표를 가져와 선후행 관계, 자원 배정, 계획 대비 실적을 관리하고 다시 Excel로 내보냅니다.
- **4D 시공 시뮬레이션** — 공정 순서대로 3D 모델을 재생하고 Gantt에서 선택한 공정의 객체를 강조해 착공 전 검토, 주간 공정회의, 발주처 설명에 활용합니다.

## 사용 환경 및 문의

웹 브라우저에서 사용하도록 설계했으며 공식 홈페이지는 Chrome을 권장합니다. 구축 형태와 데모는 제품 소개에서 확인할 수 있습니다.

- [공식 제품 소개 및 데모 문의](https://windsoft.co.kr/autoproject.html)

## English

Glazir Planner is a browser-based 4D BIM construction scheduling and simulation tool in development. Its planned workflow combines schedule-to-model matching, an Autodesk APS viewer, Excel and Gantt scheduling, and time-based playback for construction sequencing.

- [Product overview and demo information](https://windsoft.co.kr/autoproject-en.html)
