# Glazir Planner

BIM 모델과 공정표를 연결해 브라우저에서 시공 순서를 검토하는 4D BIM 시공 시뮬레이션 도구입니다. 현재 개발 중입니다.

Glazir Planner is a web-based 4D BIM construction simulation tool in development. It links building models with project schedules.
